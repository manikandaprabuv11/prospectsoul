Company Verification Module

A dense, queue-oriented workspace for selecting unverified companies, running Twilio-backed verification in the background, and reviewing durable results.

Version 1.0 · Module Verify · Status Ready for implementation · Doc index 17 of the docs/dev_docs set — companion to 13 (Requirements), 14 (Technical Specification), 15 (Implementation Plan), 16 (Kickoff Prompt)

1. Overview

The Verify experience must feel like an operational queue, not a generic CRUD screen. The active job is persistent and can be resumed after navigation.

Core invariant: the verified-company table contains verified companies only. Unverified companies appear in the selection workflow.

8. Interaction Rules

  • Do not disable the whole page while a batch is running.
  • Do not cancel a background job merely because the route changes.
  • Poll only while an active batch is non-terminal.
  • Use the existing design system and table/pagination components.
  • Show clear role-based action visibility, but enforce authorization in the backend.
  • Use accessible labels, keyboard navigation and visible focus states.
